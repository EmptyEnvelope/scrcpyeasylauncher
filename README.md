# scrcpylauncher
scrcpy简单显示配置显示器

<img width="571" height="603" alt="image" src="https://github.com/user-attachments/assets/fe9ea6ea-030c-4e1e-a623-2ec3ca6c3155" /> 

可以配置窗口模式和全屏模式

<img width="571" height="603" alt="image" src="https://github.com/user-attachments/assets/15759d6b-3f38-4046-a0ae-10fd7eccaaa1" /> 

窗口模式可以设置固定尺寸（固定窗口大小，你只能用ctrl+-来调整窗口大小，但是可以减少边缘手势误触） \
底栏防误触（上下增加黑边，改善底栏手势和状态栏下拉手感）， 同时手势辅助会提高手势触发区（部分系统不生效，自测）\
可以自由更改分辨率，刷新率，dpi，传输速率，更改dpi和分辨率可能存在危险，保持手机adb端口开放，最底下可以帮你恢复原始设置

# 使用方法
手机打开adb调试，用线连接电脑，同时打开热点连接电脑，启动器会自行执行配对，手机上请同意电脑调试 \
此后在手机下次关机或关闭开发者选项前，都可以直接点击启动器直接连接（请保证热点是连接上的）
